# Game Collection Manager

## Description
This is a Python program that allows users to manage a collection of video games using a menu-driven interface.

## Features
- Add a game
- Find a game
- View all games
- Update a game
- Delete a game
- View collection statistics
- Quit the program

## How to Run
1. Open the project.
2. Run `game_collection.py`.
3. Follow the menu prompts.
